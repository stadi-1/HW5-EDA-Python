**# HW5 - Exploratory Data Analysis with Python**



\## Project Description

This project explores the King County house sales dataset using Python. The main goal is to understand how different property features relate to house prices through data analysis and visualization.



**## Tools and Libraries**

\- Python

\- Pandas

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



**## Visualizations**

1\. Relationship between living area and house price.

2\. Distribution of house prices by waterfront properties.

3\. Number of houses sold by month.

4\. House prices by building grade.



**## Dataset**

The project uses the King County house sales dataset.



The original CSV data is excluded from this GitHub repository.
